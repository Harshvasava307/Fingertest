# Finger_Test - Typing Speed Test Application

## Original Problem Statement
Improve the Front end make frontend with amazing looking home page looks should be having of different animations and stuff like glassmorphism, Size morphism, the color theme should be neon. It's a typing test website, user wants to follow the UI/UX of MonkeyType but make it unique.

## Architecture Overview
- **Type**: Static HTML/CSS/JS Website
- **No Backend Required**: Pure frontend application
- **File Structure**: Multiple HTML pages for different test durations

## User Personas
1. **Typists & Professionals**: Want to track and improve typing speed for work
2. **Students**: Practice typing for academic and professional development
3. **Gamers/Enthusiasts**: Challenge themselves with speed tests
4. **Developers**: Check typing proficiency with code-related paragraphs

## Core Requirements (Static)
- Typing speed test with multiple duration modes (1, 2, 3, 5 minutes)
- Standard and Punctuation modes
- Real-time WPM, CPM, and mistake tracking
- Timer countdown
- Reset functionality
- Neon cyberpunk aesthetic with glassmorphism
