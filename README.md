# FingerTest

FingerTest is a web-based typing test platform that allows users to practice and measure their typing speed. The website provides a simple and customizable typing test environment where users can control the duration of the test and choose whether punctuation should be included in the typing content.

The goal of FingerTest is to provide a distraction-free interface that helps users focus on improving their typing speed and accuracy.

## Features

- Customizable typing test duration
- Option to enable or disable punctuation
- Simple and clean typing interface
- Real-time typing input tracking
- Helps users practice typing speed and accuracy

## How It Works

1. Open the FingerTest website.
2. Choose the typing test duration.
3. Select whether punctuation should be included or excluded.
4. Start typing the given text.
5. The test runs for the selected time.
6. After the time ends, the typing performance can be reviewed.

## Purpose of the Project

FingerTest is designed as a typing practice tool for users who want to improve their typing skills. It also serves as a project for developers who want to understand how typing test systems work, including timers, text rendering, and user input tracking.
